# Sophia Sprite Import v1

Copie o conteúdo deste pacote para a raiz do projeto Godot.

Arquivos:
- `assets/art/characters/sophia/sprites/atlases/sophia_idle_20f.png`
- `assets/art/characters/sophia/sprites/atlases/sophia_walk_20f.png`
- `resources/characters/sophia/sophia_sprite_frames.tres`

Configuração:
- célula: 192x192px
- atlas: 5x4
- idle: 20 frames @ 10 FPS
- walk: 20 frames @ 14 FPS
- pivô sugerido: (96, 184)

No `AnimatedSprite2D`, use:
`res://resources/characters/sophia/sophia_sprite_frames.tres`
